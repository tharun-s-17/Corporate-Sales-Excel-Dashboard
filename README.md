# Global Corporate Sales Performance Dashboard 2024

## 📌 The Business Problem
The executive team requires a consolidated view of global sales transactions to identify which regions and product categories are driving profitability versus which are operating at a loss. The goal is to isolate high-performing customer segments to optimize future sales strategies.

## 💾 The Data
The dataset consists of 18 variables tracking global corporate sales across multiple regions. It includes transaction-level data detailing `Order Date`, `Region`, `Product Category`, `Sales`, `Quantity`, and `Discount` applied. 

## 📊 Results of the Analysis
1. **Profitability:** Created custom `Net Sales` and `Profit Margin` metrics to reveal true financial health beyond raw revenue.
2. **Customer Segmentation:** Isolated purchasing trends across Consumer, Corporate, and SMB segments using dynamic Pivot Tables.


## 🛠️ Tech Stack
* **Microsoft Excel:** Advanced Pivot Tables, Calculated Columns, Interactive Slicers, Dynamic KPI Linking.

## 🚧 Limitations & Next Steps
* **Limitations:** The dataset is a simulated corporate environment; external factors like seasonality, marketing spend, and supply chain disruptions were not available for correlation.
* **Next Steps:** Integrate a cost-of-goods-sold (COGS) dataset to create a more accurate gross profit margin analysis down to the specific sub-category level.
