# Corporate Sales Performance Dashboard

## 📌 Project Objective
This project demonstrates advanced Excel data modeling and visualization techniques using a simulated global corporate sales dataset. The objective is to transform raw, transaction-level ERP data into an interactive executive dashboard that tracks regional sales health and product profitability.

## 🛠️ Tech Stack & Skills Demonstrated
* **Tool:** Microsoft Excel (Advanced)
* **Techniques:** Pivot Tables, Calculated Columns (`Net Sales`, `Profit Margin`), Dynamic KPI Linking, Interactive Slicers

## 📂 Project Files
* `Corporate_Sales_Dashboard.xlsx`: The complete workbook containing the raw dataset, Pivot Table calculation layers, and the interactive dashboard presentation layer.
* `Dashboard_Preview.png`: A high-resolution static preview of the final dashboard interface.

## 📊 Core Features
1. **Data Preparation:** Processed an 18-variable dataset of regional orders, adding custom calculated columns to extract true financial value from raw revenue figures.
2. **Pivot Table Aggregation:** Engineered multi-dimensional Pivot Tables to aggregate high-volume transaction data by Region, Category, and Customer Segment.
3. **Executive Visualization:** Built a clean, grid-less dashboard canvas featuring dynamic KPI metric cards and trend-focused charting.
